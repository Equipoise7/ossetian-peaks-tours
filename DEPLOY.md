# Инструкция по деплою на GitHub Pages

## Проблема
При деплое Single Page Application (SPA) на GitHub Pages возникает ошибка 404, потому что GitHub Pages не знает, как обрабатывать клиентский роутинг React Router.

## Решение
Мы добавили автоматическое создание файла `404.html` при сборке проекта. Этот файл перенаправляет все запросы на `index.html`, и компонент `RedirectHandler` в приложении обрабатывает эти перенаправления. Файл `404.html` создается автоматически из собранного `index.html`, что гарантирует правильные пути к ресурсам.

## Способы деплоя

### Способ 1: GitHub Actions (Рекомендуется)

1. Создайте файл `.github/workflows/deploy.yml` в корне проекта (если его нет)
2. Запушите изменения в репозиторий
3. В настройках GitHub репозитория включите GitHub Pages и выберите источник "GitHub Actions"

### Способ 2: Ручной деплой через gh-pages

1. Установите пакет `gh-pages`:
```bash
npm install --save-dev gh-pages
```

2. Добавьте скрипты в `package.json`:
```json
"scripts": {
  "predeploy": "npm run build",
  "deploy": "gh-pages -d dist"
}
```

3. Запустите деплой:
```bash
npm run deploy
```

### Способ 3: Ручной деплой через папку docs

1. Соберите проект:
```bash
npm run build
```

2. Переименуйте папку `dist` в `docs`

3. Запушите изменения в репозиторий

4. В настройках GitHub репозитория включите GitHub Pages и выберите источник "docs folder"

## Важно: Настройка base path

Если ваш сайт размещен **НЕ в корне** репозитория (например, `username.github.io/repo-name`), нужно настроить `base` в `vite.config.ts`:

```typescript
export default defineConfig({
  base: '/repo-name/', // Замените repo-name на имя вашего репозитория
  // ... остальная конфигурация
});
```

Также нужно изменить `segmentCount` в плагине `create404Html` в файле `vite.config.ts`:
```typescript
var segmentCount = 1; // Вместо 0, если сайт в подпапке
```

**Примечание:** Файл `404.html` создается автоматически при сборке проекта (`npm run build`), поэтому не нужно создавать его вручную.

## Проверка после деплоя

1. Откройте сайт в браузере
2. Проверьте, что главная страница загружается
3. Попробуйте обновить страницу (F5) - не должно быть ошибки 404
4. Проверьте консоль браузера на наличие ошибок

## Устранение проблем

### Ошибка 404 при загрузке ресурсов (CSS/JS)
- Убедитесь, что вы собрали проект (`npm run build`)
- Проверьте, что `base` в `vite.config.ts` настроен правильно
- Убедитесь, что файлы из папки `dist` задеплоены

### Белый экран
- Проверьте консоль браузера на ошибки
- Убедитесь, что файл `404.html` скопирован в папку `dist` после билда
- Проверьте, что компонент `RedirectHandler` правильно обрабатывает редиректы

### Сайт не обновляется
- Очистите кеш браузера (Ctrl+Shift+R или Cmd+Shift+R)
- Проверьте, что изменения задеплоены правильно
