# Немедленное исправление ошибки /src/main.tsx

## Проблема
Ошибка: `GET https://equipoise7.github.io/src/main.tsx 404 (Not Found)`

Это означает, что на GitHub Pages все еще старая версия сайта или браузер использует кеш.

## Решение (шаг за шагом)

### Шаг 1: Задеплойте изменения

Убедитесь, что все изменения закоммичены и запушены:

```bash
git add .
git commit -m "Fix base path and 404.html redirect script"
git push
```

### Шаг 2: Дождитесь завершения GitHub Actions

1. Зайдите на GitHub в ваш репозиторий
2. Перейдите в **Actions**
3. Убедитесь, что последний workflow завершился успешно (зеленая галочка ✅)
4. Если workflow еще выполняется, подождите 2-3 минуты
5. Если workflow завершился с ошибкой, проверьте логи и исправьте ошибки

### Шаг 3: Проверьте настройки GitHub Pages

1. Зайдите в **Settings** → **Pages**
2. Убедитесь, что:
   - **Source**: "GitHub Actions" (не "Deploy from a branch")
   - Ветка правильная (если требуется)

### Шаг 4: Очистите кеш браузера

**Важно!** Браузер может кешировать старую версию сайта.

1. **Жесткая перезагрузка:**
   - Windows/Linux: `Ctrl + Shift + R`
   - Mac: `Cmd + Shift + R`

2. **Или очистите кеш:**
   - Chrome/Edge: `Ctrl+Shift+Delete` (Windows) или `Cmd+Shift+Delete` (Mac)
   - Выберите "Изображения и файлы в кеше"
   - Нажмите "Удалить данные"

3. **Или откройте в режиме инкогнито:**
   - Chrome: `Ctrl+Shift+N` (Windows) или `Cmd+Shift+N` (Mac)
   - Это откроет сайт без кеша

### Шаг 5: Проверьте правильный URL

Убедитесь, что вы открываете сайт по правильному адресу:

- ✅ Правильно: `https://equipoise7.github.io/ossetian-peaks-tours/`
- ❌ Неправильно: `https://equipoise7.github.io/` (если сайт в подпапке)

### Шаг 6: Проверьте результат

1. Откройте сайт в браузере
2. Откройте консоль разработчика (F12)
3. Перейдите на вкладку **Console**
4. Убедитесь, что **нет ошибок 404** для `/src/main.tsx`
5. Проверьте вкладку **Network** - ресурсы должны загружаться из `/ossetian-peaks-tours/assets/...`

## Если ошибка все еще есть

### Проверка 1: Убедитесь, что новый деплой завершился

1. Зайдите в **Actions** на GitHub
2. Найдите последний workflow
3. Убедитесь, что он завершился успешно
4. Посмотрите время завершения - должно быть недавно (после вашего последнего push)

### Проверка 2: Проверьте файлы на GitHub Pages

1. Зайдите в **Actions** → последний успешный workflow
2. Найдите шаг "Upload artifact"
3. Убедитесь, что артефакт был загружен
4. Проверьте, что в артефакте есть файлы `index.html` и `404.html`

### Проверка 3: Проверьте локальную сборку

Убедитесь, что локальная сборка работает правильно:

```bash
npm run build
cat dist/index.html | grep -E "(src=|href=)"
```

Должны быть пути вида:
- `/ossetian-peaks-tours/assets/index-xxxxx.js`
- `/ossetian-peaks-tours/assets/index-xxxxx.css`

**НЕ должно быть:**
- `/src/main.tsx`

### Проверка 4: Перезапустите GitHub Actions

Если workflow завершился, но сайт не обновился:

1. Зайдите в **Actions**
2. Найдите последний workflow
3. Нажмите "Re-run all jobs"
4. Дождитесь завершения

## Важно

- **Исходный `index.html` в корне проекта** содержит `/src/main.tsx` - это нормально для разработки
- **Собранный `dist/index.html`** должен содержать пути к собранным файлам (`/ossetian-peaks-tours/assets/...`)
- GitHub Actions должен деплоить только содержимое `dist/`, а не исходные файлы
- Если вы видите ошибку `/src/main.tsx`, это означает, что либо:
  - На GitHub Pages еще старая версия
  - Браузер использует кеш
  - GitHub Pages настроен неправильно (деплоит из другой папки)

## После исправления

После того как все исправлено, сайт должен:
- ✅ Загружаться без ошибок 404
- ✅ Загружать ресурсы из `/ossetian-peaks-tours/assets/...`
- ✅ Работать при обновлении страницы (F5)
- ✅ Работать при прямом переходе по ссылкам
