# Исправление ошибок 404 для ресурсов (CSS/JS)

## Проблема
Ошибки типа:
```
Failed to load resource: the server responded with a status of 404 ()
index-Db7A3x29.css:1
```

## Причина
Base path в `vite.config.ts` не соответствует реальному URL вашего сайта на GitHub Pages.

## Решение

### ✅ Что уже исправлено:
1. Base path изменен на `/` (для корневого репозитория GitHub Pages)
2. React Router синхронизирован с base path через `import.meta.env.BASE_URL`

### Шаг 1: Проверьте URL вашего сайта

1. Зайдите на GitHub в ваш репозиторий
2. Перейдите в **Settings** → **Pages**
3. Посмотрите на **"Your site is published at:"**
4. Запомните этот URL

### Шаг 2: Настройте base path (если нужно)

**Если ваш сайт доступен по адресу:**
- `https://equipoise7.github.io/` (без подпапки) → base должен быть `/` ✅ (уже настроено)
- `https://equipoise7.github.io/ossetian-peaks-tours/` (с подпапкой) → измените base на `/ossetian-peaks-tours/`

Откройте `vite.config.ts` и измените строку 78:
```typescript
// Для корня (username.github.io):
const basePath = process.env.VITE_BASE_PATH || '/';

// Для подпапки (username.github.io/repo-name/):
const basePath = process.env.VITE_BASE_PATH || '/ossetian-peaks-tours/';
```

### Шаг 3: Задеплойте изменения

```bash
git add .
git commit -m "Fix base path to root"
git push
```

GitHub Actions автоматически:
1. Пересоберет проект с правильным base path
2. Задеплоит на GitHub Pages

### Шаг 4: Проверьте результат

1. Подождите 2-3 минуты (пока GitHub Actions завершит деплой)
2. Откройте сайт в браузере
3. Откройте консоль разработчика (F12)
4. Убедитесь, что **нет ошибок 404** для ресурсов (CSS/JS файлов)
5. Проверьте, что пути к ресурсам правильные:
   - Для корня: `/assets/index-xxx.css`
   - Для подпапки: `/ossetian-peaks-tours/assets/index-xxx.css`

## Если ошибки продолжаются

### Вариант 1: Очистите кеш браузера
- Нажмите `Ctrl+Shift+R` (Windows/Linux) или `Cmd+Shift+R` (Mac)
- Или откройте сайт в режиме инкогнито

### Вариант 2: Проверьте, что изменения задеплоены
1. Зайдите на GitHub в Actions
2. Убедитесь, что последний workflow завершился успешно
3. Проверьте, что в логах сборки видно правильный base path

### Вариант 3: Проверьте настройки GitHub Pages
1. Зайдите в Settings → Pages
2. Убедитесь, что источник установлен на **"GitHub Actions"**
3. Убедитесь, что ветка правильная (main или master)

## Важно

- После изменения base path **обязательно** нужно пересобрать проект
- GitHub Actions автоматически пересобирает при каждом push
- Если вы меняете base path локально, запустите `npm run build` для проверки
- React Router автоматически использует правильный base path через `import.meta.env.BASE_URL`
